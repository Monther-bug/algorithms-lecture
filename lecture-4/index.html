Remember · 2

Data types

Every value has a type. Python knows the type from the way you write the value.

  • int

    Whole numbers

    7-32026

  • float

    Numbers with a point

    3.598.65.0

  • str

    Text, always in quotes

    "Ali""hello""5"

  • bool

    True or False

    TrueFalse7 > 3

>>> type(5)
<class 'int'>
>>> type("5")
<class 'str'>

5 and "5" are not the same. The first is a number. The second is text, because of the quotes.

Remember · 3

input() always gives text

Whatever the user types, input() gives it back as a str. Turn it into a number before you do maths.

  • Whole numbers

    age = int(input("enter age : "))

  • Numbers with a point

    mark = float(input("enter mark : "))

  • Text, like a name

    name = input("enter name : ")

Try it

Try 7, then 7.5, then Ali.

Forget int(), and "5" + "3" gives "53", not 8.

Remember · 5

Indentation

The spaces at the start of a line tell Python which lines belong together.

even_odd.py
  1. 1n = int(input("enter number : "))
  2. 2if n % 2 == 0:ends with :
  3. 3 print("The number is even")4 spaces: belongs to if
  4. 4else:back to the left
  5. 5 print("The number is odd")4 spaces: belongs to else
  1. A line that ends with a colon : starts a group.
  2. The lines in the group move 4 spaces to the right. In VS Code, press Tab.
  3. When the group ends, go back to the left.
  4. Don't add spaces anywhere else. Even one extra space is an error:
total = a + b
IndentationError: unexpected indent

Remember · 6

if and else

if asks a question. Python runs one group of lines when the answer is True, and the other group when it is False.

if n % 2 == 0:
    print("even")
else:
    print("odd")

More than two choices? Put elif between if and else:

if mark >= 85:
    print("Excellent")
elif mark >= 50:
    print("Pass")
else:
    print("Fail")

Four things to remember

  1. 1

    input() gives text

    The colon and 4 spaces

    Write the *

    2 * (a + b), not 2(a + b).
