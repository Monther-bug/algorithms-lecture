Tool 1

mod gives the remainder

i mod 2 is what is left after you divide i by 2.

    Odd number→i mod 2 = 1

    Even number→i mod 2 = 0

    Example 1 of 4

    Tool 2

    Rows and columns

    We draw a shape one row at a time, from top to bottom.

    • i

      i is the row number. The outer loop moves down the rows.

    • j

      j is the place in the row. The inner loop moves along one row.

    • ↵

      New line and j = 1 start the next row from the first place.

    Example 3 of 4

    Write an algorithm that draws this shape

    Look closely

    4 rows. Row 1 has 1 star, row 2 has 2 stars… row i has i stars.

    Show a hint

    Use i for the row and j for the star in the row. After each row: New line, and j = 1.

    Example 4 of 4

    Write an algorithm that draws this shape

    Look closely

    5 rows of the numbers 1 to 5. In each row one number is A, and the A moves one place left on every row.

    Show a hint

    Use r for the row and c for the column. At every A, r + c = 6. Print "A" there, otherwise print c.

    Wrap-up

    Four things to remember

    1. 1

      Print and New line

      Print adds one character. New line starts the next row.

    2. 2

      mod picks the character

      i mod 2 is 0 for even numbers and 1 for odd numbers.

    3. 3

      Two loops draw a shape

      The outer loop (i) moves down the rows. The inner loop (j) moves along one row.

    4. 4

      Start every row fresh

      After New line, set j = 1 again.
